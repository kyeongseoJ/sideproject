# Novelty

<img width="3834" height="1810" alt="Novelty 화면" src="https://github.com/user-attachments/assets/3264daf5-dd13-4a40-ba32-f5f82d826249" />

새로운 자극을 소비하는 대신, 새로운 경험을 만들어보면 어떨까?

Novelty는 사용자의 성향을 바탕으로 평소와 다른 행동을 제안하고, 미션을 완료할수록 개인의 3D World가 성장하는 서비스입니다.

## 핵심 사용자 흐름

```text
로그인 또는 회원가입
  ↓
성향 선택 6문항
  ↓
성향 프로필과 3D World 확인
  ↓
오늘의 미션 후보 중 1개 선택
  ↓
미션 수행·완료
  ↓
EXP 지급 및 World 성장
```
